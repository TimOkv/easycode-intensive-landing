# «Ключ к технологиям» — лендинг интенсива EasyCode

Одностраничный лендинг практического интенсива: 10 онлайн-вебинаров, программа с расписанием,
живой статус эфира, квиз, FAQ и блок доступа к платформе.

Сайт статический: **никакой сборки, зависимостей и сервера не нужно**. Три файла и папка с картинками —
можно открыть локально, залить на любой хостинг или подключить к CDN как есть.

## Структура

```
index.html      разметка всех секций + SVG-спрайт иконок
styles.css      стили, вся палитра и типографика заданы CSS-переменными в :root
app.js          логика: расписание эфиров, обратный отсчёт, календарь, квиз, модалки
assets/
  favicon.svg   иконка вкладки
  teacher.jpg   фото преподавателя (секция «Преподаватель»)
```

Внешние ресурсы — только шрифты Geologica и Unbounded с Google Fonts (подключены в `<head>`).

## Запуск локально

Просто открыть `index.html` в браузере достаточно, но надёжнее поднять статический сервер
(так корректно работают относительные пути и параметры в URL):

```bash
python3 -m http.server 4173
# затем открыть http://localhost:4173
```

## Что настроить перед публикацией

1. **`app.js`, объект `CONFIG` в начале файла** — единственное место с настройками:

   | Поле | Что это | Статус |
   |---|---|---|
   | `roomUrl` | ссылка на вебинарную комнату платформы | **TODO:** подставить реальный `room` id вместо `ROOM_ID` |
   | `durationMin` | длительность урока в минутах | **TODO:** уточнить (сейчас 90) |
   | `time` / `tzOffset` | время эфира и часовой пояс | `17:00`, МСК (`+03:00`) |
   | `openBeforeMin` | за сколько минут до начала загорается статус «В эфире» | 10 |
   | `enrollText` | фраза, которую участник отправляет своему менеджеру | — |

   Если у каждого урока своя комната, в `roomUrl` можно использовать плейсхолдер `{lesson}` —
   он заменится номером урока (1–10).

2. **Даты уроков** — в `index.html` у карточек программы: атрибут `data-date="ГГГГ-ММ-ДД"`.
   Сейчас расписание: 22.09 – 22.10, по вторникам и четвергам. Дату в тексте карточки
   (`.lesson__date`) нужно менять вместе с атрибутом — она не генерируется автоматически.

3. **Контакт менеджера на странице намеренно не публикуется**: у каждого клиента свой канал
   (MAX / ВКонтакте / Telegram), поэтому кнопка записи копирует текст заявки, а не ведёт по ссылке.

## Демо-режимы

Чтобы посмотреть состояния расписания, не дожидаясь реальных дат, добавьте параметр к URL:

| URL | Что показывает |
|---|---|
| `?demo=live` | идёт первый эфир — активная кнопка «Подключиться» |
| `?demo=progress` | часть уроков пройдена, виден прогресс |
| `?demo=finished` | интенсив завершён — ссылки на записи |

## Деплой

Любой статический хостинг: залить содержимое репозитория в корень сайта, никакой сборки нет.

**Vercel:**

```bash
npx --yes vercel@latest deploy --prod
```

Framework Preset — **Other**, build command и output directory оставить пустыми.

**Netlify / GitHub Pages / nginx:** просто раздать папку как статику.

## Поддержка браузеров

Современные браузеры (Chrome, Safari, Firefox, Edge — последние версии). Вёрстка адаптивная,
от 320 px; учтены `prefers-reduced-motion` и безопасные зоны iOS (`viewport-fit=cover`).
